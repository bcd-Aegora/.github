# Aegora

Aegora is an agentic-payment governance DApp that applies deterministic spending policies, trust/risk checks, human approvals and verifiable evidence around autonomous machine payments.

## Repositories

- [`aegora-docs`](https://github.com/bcd-Aegora/aegora-docs) — product and architecture source of truth
- [`aegora-frontend`](https://github.com/bcd-Aegora/aegora-frontend) — Next.js console
- [`aegora-backend`](https://github.com/bcd-Aegora/aegora-backend) — control plane, API, PostgreSQL, workers and payment integration
- [`aegora-contracts`](https://github.com/bcd-Aegora/aegora-contracts) — Solidity + Hardhat
