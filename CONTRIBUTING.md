# Contributing

Org-wide defaults for Aegora repositories. Deep workflow, ADRs, and architecture live in [`aegora-docs`](https://github.com/bcd-Aegora/aegora-docs).

## Team rules

1. Work from an issue.
2. Do not push feature work directly to `main`.
3. Keep branches short-lived.
4. Open a PR when the change is reviewable.
5. CI must pass.
6. At least one human review is required.
7. Security/payment/contract changes require the appropriate code owner.
8. Update API/docs/ADR with behavior or architecture changes.
9. Never commit secrets.
10. Prefer squash merge.

## Pull-request size

Prefer small coherent PRs. Split by behavior or domain boundary, not arbitrary file count.

## AI-generated code

AI-generated changes follow the same tests, security review and ownership requirements as human-written code. The author remains accountable for every merged line.
